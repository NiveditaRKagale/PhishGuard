# ML methodology
Dataset (url,label; 0/1) → de-duplicate → extract 30 features → stratified 60/20/20 train/validation/test split (seed 42) → train LR (scaled), Decision Tree, Random Forest, optional XGBoost → select by validation F1 (ties: recall, then Random Forest) → refit on train + validation → report accuracy, precision, recall, F1, ROC-AUC, FPR, FNR, and confusion matrix on the untouched test split. Leakage controls: duplicates removed, no label-derived features, split before fitting, training + validation-only medians. Metrics are stored in `models/metrics.json` after each run. The bundled sample is synthetic; only evaluation on an appropriately sourced real dataset can support real-world performance claims.
