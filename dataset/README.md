# Dataset

`sample_dataset.csv` is **SYNTHETIC** (generated by `make_sample_dataset.py`): 300 legit-style + 300 fictional phishing-style URLs. It is only for demonstrating the pipeline; metrics on it are NOT meaningful for real-world performance.

Format: `url,label` where **0 = legitimate, 1 = phishing**.

## Using a real dataset
Download a public phishing-URL dataset (e.g. PhishTank verified-online feed + a top-sites list such as Tranco for legitimate URLs, or a Kaggle 'Phishing Site URLs' dataset). Save it as CSV, then set `URL_COL`/`LABEL_COL` in `config.py` (map labels to 0/1 if needed) and run `python train.py path/to/data.csv` or the notebook. Never open URLs from these feeds.
